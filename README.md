# AI vs 我：半年模擬交易實驗

- **A 帳戶（AI）**：2,000 元。每月最後一個交易日收盤後，從 0050 成分股中挑過去 6 個月漲最多、而且買得起的 3 檔，隔天開盤換股。
- **B 帳戶（我）**：0050、00949 各 1,000 元，第一天買進後不動。

GitHub Actions 每個交易日 15:40（台灣時間）自動用 Yahoo 財經的真實股價重新計算，並把報告發布到 GitHub Pages。

## 檔案

| 檔案 | 用途 |
|---|---|
| `config.json` | 實驗設定：開始日、金額、持有檔數、股票池、手續費 |
| `experiment.py` | 計算兩個帳戶並產生報告 |
| `history.csv` | 每天的淨值紀錄（自動更新） |
| `.github/workflows/update.yml` | 每日自動執行的排程 |

## 修改設定

在 GitHub 網頁上點 `config.json` → 鉛筆圖示 → 修改 → Commit changes，存檔後會自動重新計算。

這是模擬，不會真的下單，也不是投資建議。
