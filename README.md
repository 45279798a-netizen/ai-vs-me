# AI 交易實驗（模擬帳戶）

讓 Claude 自己判斷台股買賣，用 2,000 元的虛擬帳戶跑半年，看看 AI 操盤的結果。

每個交易日 15:40（台灣時間），GitHub Actions 會自動：

1. 用當天**開盤價**成交 AI 前一天決定的訂單（模擬，零股）
2. 用收盤價計算帳戶價值
3. 把行情、帳戶狀態整理給 Claude，讓它（可搜尋新聞）決定下一個交易日的訂單
4. 訂單通過**風控**才會成立：最多持有 3 檔、每天最多 4 筆、單一標的不超過淨值 70%、只能用現金、淨值從高點回落 40% 自動暫停
5. 把結果發布成手機版網頁

報告網址：https://45279798a-netizen.github.io/ai-vs-me/

## 設定 API 金鑰（只要一次）

Settings → Secrets and variables → Actions → New repository secret
名稱 `ANTHROPIC_API_KEY`，內容貼上 Claude API 金鑰。金鑰只存在 GitHub 的加密設定裡，程式碼和網頁都看不到。

## 檔案

| 檔案 | 用途 |
|---|---|
| `config.json` | 本金、模型、風控上限、手續費、可交易清單 |
| `agent.py` | 成交、記帳、呼叫 AI、風控、產生報告 |
| `state.json` | 帳戶狀態與所有紀錄（自動更新，不要手動改，除非要解除暫停） |

這是模擬，不會真的下單，也不是投資建議。
